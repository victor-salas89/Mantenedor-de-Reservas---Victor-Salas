# Mantenedor-de-Reservas---Victor-Salas


Aplicación de consola desarrollada en Kotlin para la Evaluación Parcial 1 de la asignatura Desarrollo de Aplicaciones Móviles (DSY1105).

Descripción

El sistema permite registrar y consultar reservas de alojamiento (Habitación, Cabaña o Departamento) manteniendo la información únicamente en memoria durante la ejecución del programa, aplicando principios de Programación Orientada a Objetos.
